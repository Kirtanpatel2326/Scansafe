# Security Policy

ScanSafe takes the security of our users and consumer health intelligence systems seriously. If you discover a vulnerability or security exposure, we appreciate your help in disclosing it to us responsibly.

## Supported Versions

Only the latest release and commits on the `main` branch are actively maintained with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you believe you have discovered a security vulnerability in ScanSafe, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Open a private advisory under the [Security Advisories tab](https://github.com/Kirtanpatel2326/Scansafe/security/advisories).
2. **Email**: Contact the maintainer directly at [kirtanpatel2326@gmail.com](mailto:kirtanpatel2326@gmail.com) with the subject prefix `[SECURITY VULNERABILITY]`.

### What to Include

To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept (PoC) code to reproduce the issue.
- Affected components (routes, modules, or services).
- Any suggestions for mitigation or fixes.

## Response SLA

- **Acknowledgment**: Within 24 hours of report receipt.
- **Triage & Assessment**: Within 48 hours.
- **Fix & Disclosure**: We aim to release a patch within 7 business days depending on complexity.

## Responsible Disclosure & Safe Harbor

We commit to working cooperatively with security researchers. As long as you comply with the following guidelines, we will not pursue legal action against you:
- You make a good-faith effort to avoid privacy violations, destruction of data, and service interruption.
- You do not access or modify data belonging to other users.
- You give us reasonable time to investigate and remediate the vulnerability before publicly disclosing it.
